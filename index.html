● LIVE

Delivery Economics

The situation: a white-glove delivery operation losing $1,156 on 13 orders. What I did: rebuilt 171 order lines into a 7-day operating model and traced every dollar. The result: labor is 92% of cost and happens inside customers' homes, where routing can't touch it — so the fix is pricing ($150 + $0.25/cu ft), not trucks. Plus the full operating system to run the day.
