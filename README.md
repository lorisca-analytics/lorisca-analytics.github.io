
## Editing system

This page is edited from the admin at https://lori-sca.github.io/admin/ (Page tab).
Section order, hidden sections, looks and builder-added sections live in
`data/page.json` under `layout`. The shared skeleton and theme load from
https://lori-sca.github.io (`skeleton.js`, `theme.js`, `theme.css`); see that repo's
README for the rules. Never rename or remove JSON keys.
